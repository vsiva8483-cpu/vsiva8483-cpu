# Setup

This is a repo scaffold, not just a README — it generates its own SVG
assets the same way the reference profile does (custom scripts + a
GitHub Action), instead of embedding third-party stats-card services.

## 1. Create the repo

Create a repo named exactly `vsiva8483-cpu` under your account
(a repo with the same name as your username is what GitHub renders
on your profile page).

Push everything in this folder to that repo's `main` branch:

```
README.md
info-card.svg              (generated — see step 3)
contrib-heatmap.svg         (generated by the Action, see step 4)
siva-ascii.svg              (optional — needs a photo, see step 5)
data/profile.json
scripts/generate_info_card.py
scripts/generate_heatmap.py
scripts/generate_ascii.py
.github/workflows/update-profile.yml
```

## 2. Install dependencies locally (optional, for testing)

```bash
pip install pillow requests
```

## 3. Generate the info card

```bash
python scripts/generate_info_card.py
```

This reads `data/profile.json` — edit that file any time your stack,
highlights, or links change, then re-run the script.

## 4. Enable the contribution heatmap

The heatmap script calls GitHub's GraphQL API, which needs an
authenticated token with `read:user` scope.

1. Create a classic Personal Access Token with `read:user` scope.
2. In the repo, go to **Settings → Secrets and variables → Actions**
   and add it as a secret named `GH_TOKEN`.
3. The included workflow (`.github/workflows/update-profile.yml`)
   runs daily and on every push, regenerates `contrib-heatmap.svg`,
   and commits it back automatically.

You can also trigger it manually from the **Actions** tab
(`workflow_dispatch`) to generate it immediately.

## 5. (Optional) Add the ASCII portrait

1. Add a photo to the repo root named `source-photo.jpg`
   (a clear, front-facing photo works best).
2. Run:
   ```bash
   python scripts/generate_ascii.py
   ```
3. Commit the resulting `siva-ascii.svg`.

If you skip this, remove the left column of the table at the top of
`README.md` so it doesn't reference a missing file.

## 6. Verify before publishing

Open `README.md` in a local Markdown previewer (or push to a private
repo first) and confirm both SVGs render — GitHub raw SVG rendering
can behave slightly differently from local previews.
